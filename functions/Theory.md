## What are Functions?: 
Functions act as independent blocks of code that perform specific tasks. They improve code readability and eliminate redundant logic 

## Syntax and Structure: 
Includes the function's return type, name, parameters, and the function body within curly braces

## Parameters vs. Arguments: 
Parameters are the variables defined in the function signature, while arguments are the actual values passed during a function call

## Functions in Memory:
Explained via the Call Stack. Each function call creates a new stack frame in memory, which is removed once the function completes 

## Pass by Value: 
When primitive data types are passed to a function, the function works on a copy of the original variable, meaning changes inside the function do not affect the original variable in the calling function
